# Declaración de Integridad Académica
## Proyecto Pavanamoon — Bases de Datos, Universidad Mariano Gálvez de Guatemala

> **Plantilla sin firmar.** Si la guía del curso trae un formato oficial,
> úsese ese formato y adáptese este texto. Cada integrante firma solo si está
> de acuerdo con cada punto.

Los integrantes abajo firmantes declaramos que:

1. **Autoría.** El proyecto Pavanamoon (análisis, diseño, base de datos,
   aplicación web y documentación) es trabajo del equipo. Las fuentes
   externas consultadas se citan en la documentación correspondiente.
2. **Uso de inteligencia artificial.** Usamos asistentes de IA (Claude de
   Anthropic, Gemini y otros que se indican en la bitácora) como apoyo para
   redactar, revisar, generar código y probar. Ese uso está declarado en
   `docs/bitacora-ia/BITACORA_IA.md`, que registra en cada consulta qué se
   pidió, qué se obtuvo y cómo lo validó el equipo, incluidos los errores de
   la IA que se detectaron y corrigieron.
3. **Validación y responsabilidad.** Revisamos, ejecutamos y comprendemos el
   código y los documentos entregados, y asumimos la responsabilidad por su
   contenido, se haya generado con o sin ayuda de IA. Cada integrante puede
   explicar el funcionamiento del sistema en la defensa oral.
4. **Veracidad de las evidencias.** Los resultados de las pruebas provienen
   de ejecuciones reales. Cada evidencia indica dónde y quién la ejecutó:
   entorno local aislado, máquina de un integrante o Railway. No incluimos
   capturas ni resultados alterados o inventados.
5. **Datos.** El sistema publicado usa solo datos ficticios. No contiene
   datos personales reales de clientes ni de empleados.
6. **Credenciales.** El repositorio no contiene credenciales de producción.
   Las contraseñas que aparecen son de desarrollo local y están documentadas
   como tales.
