# sql/views

Esta carpeta existe para respetar la estructura obligatoria del proyecto
(Sección 7 de la guía) y se llenará en la **Entrega 3** con las vistas
requeridas por la guía, por ejemplo:

- Vista de stock actual por producto/variante con alerta de `stock_minimo`.
- Vista de ventas por cliente (útil para reportes de mayoristas).
- Vista de historial de movimientos de stock por variante.

Convención de nombres: `sql/views/NN_nombre_vista.sql`, un `CREATE VIEW` por
archivo (estándar S2), con encabezado (estándar S3) igual que los scripts de
`sql/ddl/`.
